No app to install on the phone

Point your phone.
Click the screen.

Mobile Remote turns any phone into a Wii-style pointer for your laptop. Aim the top edge at the screen and the cursor follows. Tap to click, swipe to scroll, type on the phone's keyboard.

Get the desktop app Try it in the browser

For Windows, macOS and Linux · works with any phone browser

Set up in under a minute

The phone only needs its web browser. Your laptop runs a small helper that pairs with it over a QR code.

Run the app

Start Mobile Remote on your laptop. It opens a secure link for your phone and shows a QR code.

Scan the code

Point your phone's camera at the QR code and tap Start motion. On iPhone, allow motion access.

Point at 4 corners

Aim the phone's top edge at each corner of the screen and tap. After that, the cursor goes where you point.

Two ways to use it

Use the desktop app to control your whole computer, or try the browser demos without installing anything.

Desktop app

Control your whole computer

  • Moves your real mouse, so it works in any app and any browser tab
  • Scroll with two fingers, type with the phone keyboard (emoji and autocorrect too)
  • Starts the relay and the secure tunnel for you, then shows a QR code
Looking for downloads…
The app uses a free Cloudflare tunnel to give your phone an HTTPS link. Install it once: winget install --id Cloudflare.cloudflared on Windows or brew install cloudflared on macOS.
In the browser

Try the demos

  • Pointer Playground: light up buttons, hit targets, type on an on-screen keyboard, or paint, all by pointing
  • Yes / No: point left or right of the screen and tap to choose
Phones only share motion sensors with HTTPS pages, so open this site through its https:// address on your laptop. The QR code on each demo then points at the right place.

Everything from one hand

The top half of the phone has the controls. The bottom half is a touchpad.

PointAim the top edge and the cursor follows.
TapClick. Uses where you pointed just before your finger landed.
DragNudge the cursor precisely onto small targets.
Two fingersScroll, just like on the phone itself.
HoldRecenter when the gyro drifts. Aim at the middle first.
KeyboardType into whatever has focus. Ctrl, Alt and arrows included.

Add it to your own web app

Load remote-client.js, show a QR code with a room code, and react to the phone. pointer.js turns pointing into screen coordinates after a 4-corner calibration.

The relay is one small Node server: run npm start, or deploy the included Dockerfile anywhere with HTTPS.

import { connectRemote, makeRoomCode } from "/remote-client.js";

const room = makeRoomCode();
// show `${origin}/phone?room=${room}` as a QR code

connectRemote({
  room,
  onPoint: ({ v }) => { /* where the phone points */ },
  onClick: () => { /* the touchpad was tapped */ },
  onStatus: ({ phone }) => { /* paired or not */ },
});
